# Fictional name-generation reference data

The Kingswell simulation uses this surname reference list only to generate fictional NPC and entity names. It is not a list of Kingswell residents and does not identify real people in the game.

- Source project: https://github.com/solvenium/names-dataset
- Source file: https://github.com/solvenium/names-dataset/blob/master/dataset/Surnames.txt
- Upstream description: multinational first names and surnames, based on the Wiktionary Names Appendix.
- Upstream licence: MIT; see `LICENSE.txt`.
- Local copy: `Surnames.txt`.

Names are treated as a reference vocabulary, not as claims about a person's ethnicity, nationality, family or identity. Family membership is determined by Kingswell's own fictional relationship records, never by a surname match alone.

The database stores a normalized catalogue and allocates each active family surname to one family identity. Existing person IDs, relationships and life records are preserved when names are corrected.
